# Student Grade Calculator

## Project Overview

The Student Grade Calculator is a beginner-friendly Python project that calculates a student's total marks, average marks, grade, and pass/fail result based on the marks entered for each subject.

This project was developed as part of my Python programming internship task.

## Features

- Accepts student name
- Accepts the number of subjects
- Accepts marks for each subject
- Validates marks between 0 and 100
- Calculates total marks
- Calculates average marks
- Assigns a grade based on the average
- Displays Pass or Promoted
- Uses Python functions, loops, lists, and conditional statements

## Grading System

| Average Marks | Grade |
|---|---|
| 90–100 | O |
| 75–89 | A+ |
| 60–74 | A |
| 55–59 | B+ |
| 50–54 | B |
| 45–49 | C |
| 40–44 | D |
| 0–39 | F |
